# CLAUDE.md — power-to-flops

## What this repository is

A single-manuscript repository: `paper/` plus exactly the code, records, and figures that
reproduce its numbers. It was split out of a larger research repository — see
`PROVENANCE.md`. Keep it that way. Work that is not about this manuscript's results does
not belong here.

`README.md` is the front page and the reproduction guide; it is the closest thing to a
spec. `paper/main.tex` is the authority on what is claimed.

## Reproducibility (first-class concern)

1. **Every figure is regenerated by a script in `scripts/`.** No hand-made figures.
2. **`results/bench/measured_bands.json` is the single source of measured truth.** Every
   quoted number and every figure reads from it. After any recapture, regenerate the
   artifact *first*, then the figures.
3. **Figures are pinned to that artifact.** `powertoflops.bench.records.record_for()` reads
   each figure's input record from the artifact's `inputs` block, so a figure can only plot
   the records that priced the bands it is captioned against. It fails loudly on a missing
   or renamed record rather than guessing — never replace this with newest-by-mtime
   selection.
4. **`plotstyle.save` suppresses the PDF `CreationDate`**, so re-running a plot script on
   unchanged data is byte-identical. Do not reintroduce timestamp churn: a clean
   `git status figures/` after a rerun is a real regression check.
5. **No magic numbers.** Parameters live in `powertoflops/config.py` or at the top of the
   script that uses them.
6. **Dependencies are pinned** in `requirements.txt` / `requirements-gpu.txt`. The GPU pins
   are load-bearing — int8 kernel dispatch moves the measured band edges.

## Conventions

- **Never work directly on `main`.** Branch (`feat/`, `fix/`, `refactor/`, `docs/`).
- **Commit early and often**, Conventional Commits format.
- Run `pytest -m "not gpu"` before committing. GPU-marked tests need a real A100 + NVML
  under Slurm.
- `paper/main.pdf` is a build artifact and is gitignored. Build it, don't commit it.

## Gotchas

- The library package is `powertoflops`, deliberately **not** `code` — the old name shadowed
  the stdlib `code` module that newer `pdb` imports eagerly. Do not rename it back.
- `data/qblock/*.npz` is untracked and sha256-pinned by the committed manifest. The loader
  hard-fails on a mismatch with no synthetic fallback.
- Records embed an `analysis_git_commit` that resolves in the *source* repository, not this
  one (`PROVENANCE.md` explains). The local check is that `analyze_bands.py` reproduces the
  committed artifact.
- This repository is intended to become public. Nothing goes in that could not be published:
  no placeholder text (arXiv treats it as evidence of unreviewed LLM output), no internal
  review correspondence, no unpublished collaborator material.
